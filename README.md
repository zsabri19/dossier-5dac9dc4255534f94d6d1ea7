# The Dossier — NASTP AI Incubation EOI submission

Interactive review package for **EOI-10-1/092025/1/009** — incubation partners to establish and manage centres at GWALPHA Tech (Pvt) Ltd parks, proposed for **NASTP Delta Park Lahore**.

**Lead applicant:** WiseDezine · **Procuring entity:** GWALPHA Tech (Pvt) Ltd · **Ecosystem:** NASTP

## What this is

A self-contained static site presenting the complete tender submission as an interactive review dossier:

| Section | Contents |
|---|---|
| 01 · The bid | Value proposition, scope, organisation relationships |
| 02 · Programme | ClarityOS six-stage journey, six clarity questions, vertical × cluster map |
| 03 · Trinity | The 45-mark international / industry / academia partnership stack |
| 04 · Commercial | Interactive cost-to-serve stack and 24-month arithmetic |
| 05 · Evidence | Live release checklist and evidence status by claim |
| 06 · Documents | The full document library — every HTML and Markdown file in the package |

## Running locally

Open `index.html` in a browser. No build step, no dependencies.

## Access model

This repository is intentionally **unlisted**: the URL is the access credential. Search indexing is disabled via `robots` meta and `robots.txt`. Please do not publish the URL outside the review group.

## Before release

The checklist in section 05 and `docs/06_Review_and_Seal/Final_Assembly_Checklist.md` list the items still required — principally WiseDezine's registration, signatory authority, tax and GST particulars, financial statements, confirmed staff CVs, and the signed partner LOI returns.
